# أدوات ربط CH05 (GeoScan3D) بالكمبيوتر

هذا المجلد يحتوي عدة أدوات مستقلة، رتّبها حسب الأولوية:

1. **`GeoScan3D_Viewer.py`** — أداة عرض مفتوحة المصدر تتصل مباشرة عبر **BLE**
   بدون أي جسر أو منفذ COM، وتفهم بروتوكول الفيرموير الحقيقي مباشرة. **موصى بها
   أولاً** لأنها أبسط أداة وأقل نقاط فشل.
2. **`GeoScan3D_Viewer_USB.py`** — نفس الفكرة لكن عبر **كابل USB سلكي مباشر**
   (بدون بلوتوث إطلاقاً). استخدمها فقط كبديل تشخيصي إذا استمرت مشاكل BLE على
   جهاز كمبيوتر معيّن (مشاكل مكدس بلوتوث ويندوز/WinRT معروفة على بعض الأجهزة) —
   تتطلب فيرموير **v9.6 فأحدث** (يضيف استقبال أوامر عبر Serial). هذا لا يحل مشكلة
   الاستخدام الميداني اللاسلكي، لكنه يثبت أن الفيرموير والبروتوكول يعملان بشكل
   صحيح، بمعزل عن أي مشكلة بلوتوث.
3. **`CH05_Bridge.py`** (+ الجسر المقسّم `ble_com_bridge_win.py`) — جسر BLE↔COM
   لمن يحتاج تحديداً منفذ COM حقيقي (لبرنامج خارجي كـ Visualizer 3D)، وليس أداة
   عرضنا الخاصة. **تنبيه:** برنامج OKM Visualizer 3D Studio التجاري يتوقع
   بروتوكولاً خاصاً بشركة OKM غير موثّق علناً، وقد لا يتوافق مع بروتوكول
   GeoScan3D المخصص حتى لو نجح الاتصال بمنفذ COM — استخدم أداتي BLE/USB أعلاه
   للتأكد من عمل الجهاز أولاً.

## GeoScan3D_Viewer.py / GeoScan3D_Viewer_USB.py — الاستخدام

انقر نقرتين على `Run_GeoScan3D_Viewer.bat` (BLE) أو `Run_GeoScan3D_Viewer_USB.bat`
(USB) — تُثبّت المكتبات المطلوبة تلقائياً عند أول تشغيل. في نسخة BLE اضغط
Connect (اسم الجهاز الافتراضي CH05). في نسخة USB اختر منفذ COM الذي يظهر عند
توصيل الكابل (غالباً أعلى رقم COM جديد يظهر في القائمة) واضغط Connect. كلتاهما
تعرضان القيم الحية ورسماً بيانياً وأزرار CAL/MAGCAL/PULSE/START/STOP/THR.

# جسر BLE ↔ COM لجهاز CH05 (GeoScan3D)

شريحة ESP32-S3 داخل M5Stack CoreS3 لا تملك راديو Bluetooth Classic، لذا لا يمكنها
فتح منفذ COM كلاسيكي تلقائياً كما تفعل وحدة CH05/HC-05 الحقيقية عبر SPP. هذا
الجسر يسد الفجوة على ويندوز: يتصل بالجهاز عبر BLE وينشئ طرفاً على منفذ COM
افتراضي، فيبدو الجهاز لأي برنامج (مثل Visualizer 3D) كأنه CH05 حقيقي متصل عبر
منفذ تسلسلي عادي.

**ملاحظة مهمة:** لا تُقرن (Pair) جهاز `CH05` يدوياً من إعدادات بلوتوث ويندوز —
هذا الإقران قد ينجح ظاهرياً (ويُنشئ حتى منفذ COM "وارد" تلقائي) لكنه لا ينقل أي
بيانات فعلية لأن الجهاز لا يدعم SPP الكلاسيكي أصلاً. احذف أي إقران قديم كهذا،
واترك الاتصال الفعلي للجسر أدناه فقط.

## المتطلبات

- ويندوز 10/11 مع بلوتوث منخفض الطاقة (BLE) يدعمه.
- بايثون 3.9 أو أحدث ([python.org](https://www.python.org/downloads/) — فعّل خيار
  "Add python.exe to PATH" أثناء التثبيت).
- [com0com](https://sourceforge.net/projects/com0com/) — أداة مجانية لإنشاء زوج
  منافذ COM افتراضية (استخدم النسخة الموقّعة Signed لتفادي مشاكل تفعيل التوقيع
  على ويندوز).

## الطريقة الأسهل — نقرة واحدة (CH05_Bridge.py + Run_CH05_Bridge.bat)

هذا هو الملف الموصى به: كل شيء مدمج في `CH05_Bridge.py` وحده، ويُثبّت مكتباته
تلقائياً عند أول تشغيل.

1. **ثبّت com0com** وأنشئ زوج منافذ افتراضي، مثلاً `COM10 <-> COM11`:
   افتح "Setup Command Prompt" التي تثبتها com0com واكتب:
   ```
   change CNCA0 PortName=COM10
   change CNCB0 PortName=COM11
   ```

2. **حمّل** `CH05_Bridge.py` و`Run_CH05_Bridge.bat` إلى مجلد واحد على جهازك.

3. **شغّل الجهاز** (M5Stack مع فيرموير CH05) وتأكد أنه غير مقترن مسبقاً في
   إعدادات بلوتوث ويندوز (احذف أي إقران قديم باسم CH05 أو GeoScan3D).

4. **انقر مرتين** على `Run_CH05_Bridge.bat`. سيثبّت المكتبات المطلوبة تلقائياً
   في أول مرة، ثم يسألك عن رقم منفذ COM — أدخل `COM11` (الطرف الذي "يستهلكه"
   الجسر). اترك النافذة مفتوحة وهي تعمل.

5. **افتح Visualizer 3D** ووجّهه إلى الطرف الآخر من الزوج (`COM10` في هذا
   المثال) — البروتوكول (الحزم الثنائية، أوامر THR/CAL/STEP/...) لم يتغيّر
   إطلاقاً، فقط طريقة نقله.

## طريقة بديلة من سطر الأوامر

نفس الملف يقبل معطيات سطر الأوامر مباشرة إن كنت تفضّل ذلك بدل الأسئلة التفاعلية:
```
python CH05_Bridge.py --com COM11
python CH05_Bridge.py --com COM11 --name CH05 --address AA:BB:CC:DD:EE:FF
```

توجد أيضاً نسخة مقسّمة بنفس المنطق (`ble_com_bridge_win.py` + `requirements.txt`)
لمن يفضّل تثبيت المكتبات بنفسه عبر `pip install -r requirements.txt` بدل التثبيت
التلقائي.

## ملاحظات

- الجسر يمرّر البايتات الخام في الاتجاهين دون تفسيرها، لذا يبقى توافقاً كاملاً
  مع أي برنامج يتحدث بروتوكول GeoScan3D الحالي عبر منفذ تسلسلي.
- إن كان للجهاز عنوان MAC ثابت وتريد تفادي البحث بالاسم في كل مرة، استخدم
  `--address AA:BB:CC:DD:EE:FF` بدل `--name`.
- إغلاق النافذة (أو Ctrl+C) يقطع اتصال BLE بالجهاز ويحرر منفذ COM.
